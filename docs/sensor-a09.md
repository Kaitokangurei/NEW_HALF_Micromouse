# A09：前壁用10°・横壁用30°

[3Dビューア](../mechanical/assembly-a09.html) / [組立STEP](../mechanical/assembly-a09.step) / [プレビュー](../mechanical/sensor-a09.png) / [メイン基板STEP](../mechanical/pcb-a09-concept.step)

**真正面を0°、真横を90°**とするユーザー指定を反映した。
右は正角度、左は負角度として、発光部と受光部を同じ方向へ向ける。

| 用途 | 左 | 右 | 基板中心X,Y [mm] |
|---|---:|---:|---|
| 前壁用 | −10° | +10° | X=±7、Y=7.5 |
| 横壁用 | −30° | +30° | X=±13.6、Y=16.5 |

横壁用も前方へ向けた30°であり、真横から30°戻した60°ではない。
機体座標では正面が−Y、右が+X。光軸の水平単位ベクトルは `(sin θ, −cos θ, 0)`。

A08から基板と差込タブ・メイン基板の長穴を一緒に回転させた。前壁用は前端の余裕のため0.5 mm後方へ、横壁用はファン支持部との余裕のため左右へ各1 mm動かした。
A07のメイン基板から長穴を作り直しているため、旧角度の穴は残していない。
ファンΦ22・ファン軸Y=21.75、中央車軸、電池配置は維持する。

センサは同じOSI5FU3A11CとLTR-209を上下2段で4組。小基板寸法・取付方式・光軸高さは[A08](sensor-a08.md)と同じ。
**LTR-209は引き続き外形未確認の予約形状**。照射・受光角、壁の反射、上下の光軸間隔、近距離の測距性能は実機調整が必要。
角度変更に合わせて距離校正と壁判定を行う。光軸が空いているだけで横壁を正しく測距できることを保証しない。
