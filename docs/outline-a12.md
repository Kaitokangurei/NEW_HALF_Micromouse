# A12：センサを基板外形の内側へ収める

[上面確認図](../mechanical/sensor-a12-top.png) / [3Dビューア](../mechanical/assembly-a12.html) / [組立STEP](../mechanical/assembly-a12.step) / [画像](../mechanical/sensor-a12.png) / [基板STEP](../mechanical/pcb-a12-concept.step)

ユーザーの「上から見たときにセンサがはみ出さず、基板外形と隙間を設ける」を反映した。
センサ本体だけでなく、リード・立て基板・差込タブを含め、メイン基板の外形から**名目1 mm以上内側**に収まる条件で検査する。
基板の穴・スリットではなく、外周との距離を評価する。

## 変更内容

センサを内側へ移動すると吸引部との余裕が減るため、今回の案ではセンサの位置と角度を保ち、**前側のメイン基板外形を拡張**した。
機体の目標幅39 mm・全長66 mmを超える拡張ではない。

| 部位 | A11 | A12 |
|---|---|---|
| 基板前端 | Y=5 | Y=1 |
| 前側左右の端 | X=±17 | X=±18.5（幅37） |
| 前端の角 | X=±13、Y=5から面取り | X=±15.5、Y=1からX=±18.5、Y=4へ面取り |
| 車輪切欠き・後側外形 | 既存形状 | 維持 |
| 前壁用センサ | タイヤ寄り、左右±10° | 維持 |
| 横壁用センサ | 前方、左右±60° | 維持 |
| ファン・3点支持・電池・駆動部 | A11配置 | 維持 |

旧外形との差分だけを追加して、取付穴・センサスリット・吸入口を保つ。
基板の追加面積と質量による完成機の重心変化は未評価。前側の基板面が増えるため、床面反射や吸引流路への影響も今後確認する。

## 上面での隙間の確認方法

[生成スクリプト](../mechanical/build_outline_a12.py) / [検査JSON](../mechanical/sensor-a12-checks.json)

各センサ関連部品のCAD外接箱をXY面へ投影した長方形を作り、すべての長方形が基板外形の内側にあることと、その外周までの距離を検査する。
外接長方形は部品の実際の投影輪郭を包むため、モデル形状に対して保守的な隙間の下限になる。
上面確認図の橙色はこの長方形、緑が基板外形、青矢印が向き。実際の部品輪郭や取付穴の製造図ではない。

今回の検査ではセンサ関連20部品がすべて内側に収まり、外接矩形に基づく最小隙間は**約1.251 mm**だった。機体外接寸法は幅38.8 × 長さ60.0 × 高さ約19.887 mmで、目標外形内。94部品・132ソリッドをSTEPに保存し、読み戻しも有効。

拡張した基板と駆動部・支持部・センサの交差、Φ22羽根の回転領域、光軸中心線、STEP読み戻し、目標外形も再確認する。
光軸中心線の確認だけでは、照射角・受光角全体や基板反射の影響は判断できない。

**隙間は現モデルの名目寸法に対する値**。LTR-209は未確認のΦ4.2×6予約形状を継続する。
発光LED公差、取付角度ずれ、リードの曲がり、はんだ・配線・接着剤、基板外形の製造公差は含まない。
実寸の受光部品に置換し、これらを加えた状態で最終隙間を確認する。製造用確定データではない。

```sh
XDG_CACHE_HOME=/tmp/mouse-cad-cache MPLCONFIGDIR=/tmp/mouse-matplotlib /workspace/.tools/mouse-view/bin/python mechanical/build_outline_a12.py
```
