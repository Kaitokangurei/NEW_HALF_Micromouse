# A04の重心調査

追記：[各グループ5 gというユーザー指定での概算](center-of-gravity-5g.md)を作成した。以下の実測値・材質設定の調査結果とは分けて扱う。

## 結論

**現時点では完成機の重心座標を確定できない。** A04の配置は分かるが、部品質量・部品内部の質量分布が未入力で、未設計の部品もある。
元STEPの材質設定を調べたところ、明らかに実物の質量計算に適さない設定が見つかったため、その密度から合成重心を算出する方法は採用しない。
全体重心は未確定のままにし、根拠のない座標を記入しない。

左右部品の質量と質量分布が対称なら左右重心Xは約0となるが、現在それを実測して確認したわけではない。
電池を車軸上に置くことで、電池自身の前後モーメントを抑える方針になっている。
ただし、モータ・吸引部・その他の部品によるモーメントが相殺される保証はない。

## 前後バランスの条件

体積図心が実際の各部品重心に近いと**仮定する簡略モデル**では、
左右駆動モータの合計質量をD、ファンモータ・羽根・マウントの合計質量をFとすると、
この2グループの前後モーメントはおおよそ `7.83 D − 16.5 F` [g·mm]。

- D/F ≈ 2.11なら、この2グループだけの前後モーメントは相殺する。
- D/Fが2.11より大きければ、この2グループでは後方寄り。
- D/Fが2.11より小さければ、この2グループでは前方寄り。

この比較には車輪・ギア・マウント・実装基板・センサ・ケース・配線等の残りの質量を含めていない。
この比だけで機体全体が前後どちらに重いかを断定しない。

完成機の重心は `Σ(m_i × r_i) / Σm_i`。前後オフセットはそのY座標から33を引く。
例えば**総質量が23 gだと仮定した場合**、1 gの部品を前後へ10 mm移動すると重心は約0.43 mm動く。
23 gは設計目標であり、現在の総質量を確認した値ではない。

## 実測値を反映する手順

1. [質量入力CSV](../mechanical/mass-input.csv)に各グループの質量と重心座標を入力する。電池・駆動部・吸引部を優先して測る。
2. リードやネジを含めるグループを決め、二重計上や含め忘れを防ぐ。図心で重心位置を近似する場合はnotesに「近似」と明記する。
3. 不要・別グループへ含めた行は質量0と明記する。空欄は未測定として残す。
4. リポジトリのルートで `python3 mechanical/calculate_cg.py mechanical/mass-input.csv` を実行する。

現在は未入力10グループのため、計算器は`status: incomplete`、`cg_mm: null`を返す。
未入力を0として計算することはない。全行入力後も結果の信頼性は測定・近似・網羅性に依存する。
計算器は対称配置・不等質量の解析解、未入力、明示的ゼロ、負値・非有限値の拒否を確認済み。

監査の再実行はCAD用環境で以下を実行する（実行確認は `/tmp/mouse-layout-tools` を使用）。

```sh
XDG_CACHE_HOME=/tmp/mouse-cad-cache /workspace/mouse-cad-tools/bin/python mechanical/audit_mass_properties.py /path/to/TORANEKO.Mk3_v36.step
```
