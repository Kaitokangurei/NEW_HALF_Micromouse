# 配置検討 A01

**更新：駆動部のSTEP測定に基づく[A02](layout-a02.md)を参照。A01のトレッド32 mm案は採用しない。** 以下は初期検討の記録。

## 合意した方針

部品・回路はトラ猫 Mk3、基板形状は新規、ソフトは自作とする。
ユーザー提供の大会資料の数値は「66x39x22 [mm] 23[g]」。写真との対応から全長66、全幅39、高さ22 mmと仮解釈する。
タイヤ・スカート・配線・コネクタを含む完成機をこの範囲に収める目標とし、基板寸法とは区別する。
重量23 gは目標。部品の実測重量がないため、重量成立性は未検証。

## A01の座標と配置

単位はmm。上面図のXは左右（中心0）、Yは機体前端0から後方66。Zは床0から上向き。
原点・配置は新機体独自で、元のCAD座標とは異なる。

| 要素 | 配置・寸法 | 確度 |
|---|---|---|
| 完成機の外接枠 | X=-19.5〜19.5、Y=0〜66、Z=0〜22 | 目標。長方形はスカート輪郭そのものではない |
| 基板の候補 | 最大幅34、Y=5〜61（長さ56）、角落とし・車輪切欠き | 仮案。穴・配線・センサを未配置 |
| 車軸 | Y=40、左右車輪中心X=±16 | 仮案。トレッド32を候補とする |
| 車輪 | 径14、幅5を仮置き | 幅は未測定。左右を含む全幅37、目標枠まで片側1 mm |
| 吸引ファン | 中心(0,18)、Φ30 | 中心位置は仮。ケース・支持部・排気流路は未配置 |
| 電池2本 | 中心X=±6.3、中心Y=46、各12×25 | 仮案。セル間0.6、電池だけの全幅24.6 |
| センサ | 前端と左右側面の配置を今後検討 | 図中の矢印は測距方向の候補で、ホルダー寸法や確定光軸ではない |

ファンと電池の上面投影の間は0.5 mmしかなく、ケース・配線の余裕としては不足する可能性がある。
電池は車軸・駆動部の上に積む想定。上下方向を分離する必要があり、上面図の重なりだけでは干渉を判断できない。
モータ・ギア・磁石・エンコーダ基板はまだ配置していない。単にタイヤが枠内にあることを駆動系成立の証拠にしない。

## 現時点の成立性と制約

1. 元の基板幅40 mmは目標全幅39 mmを1 mm超える。そのままの外形は使えない。幅34 mmの候補へは6 mm縮小となり、再配置・再配線が必要。
2. トレッド32の場合、左右同幅のタイヤを想定すると全幅は32＋タイヤ幅。39 mmに収める理論上限は幅7 mmだが、製造公差や突起の余裕は残らない。A01の幅5 mmは仮定で、実タイヤ・ホイール・ギアの幅を確認する。
3. Φ30ファンと幅34の基板候補の差は片側2 mm。ファンケース・支持部・ネジ・センサ・銅箔の隙間を含めた検証は未実施。Φ30が収まるだけでは吸引部全体が収まるとは限らない。
4. 元の高さ関係を参考にすると、床から基板下面2.36＋電池底11.1＋電池厚6 = 19.46 mm。元ホルダー上端は床から20.16 mmで、22 mmまで1.84 mm。これは旧配置の算術であり、A01の高さを検証した値ではない。コネクタ・配線・ファンモータが制限を超える可能性がある。
5. 車軸位置やファン位置を変えれば、重心・旋回特性・吸引面積が変わる。type6やトラ猫の走行パラメータはそのまま採用しない。

## 次の設計工程

1. STEP v36から左右の駆動部（モータ、ギア、軸受、車輪、磁石、エンコーダ）の外接寸法と軸位置を取得する。部品の実物寸法・購入型番とも照合する。
2. 駆動部をひとかたまりで配置し、全幅39 mmに収まるか確認する。収まらない場合はまずマウント・ホイールの形状や配置を検討し、同じ部品を使う方針を勝手に変更しない。
3. ファンケース・流路・センサホルダーを含む3D配置と高さ断面を作る。電池の配線・取り外し空間も含める。
4. 実測または根拠のある部品質量を積み上げ、23 gの重量予算を作る。
5. 配置が成立したらKiCadのEdge.Cutsと取り付け穴を確定し、回路・配線へ進む。

現段階では製造用DXF・Gerber・PCBや穴座標を確定しない。図は配置検討用で、干渉検証や製造性確認を終えた設計ではない。
