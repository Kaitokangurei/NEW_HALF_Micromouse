# A11：吸引部の上部固定基板を4点から3点支持へ

[3Dビューア](../mechanical/assembly-a11.html) / [組立STEP](../mechanical/assembly-a11.step) / [画像](../mechanical/sensor-a11.png) / [上部固定基板STEP](../mechanical/upper-plate-a11.step) / [メイン基板STEP](../mechanical/pcb-a11-concept.step)

これまでの4点は、吸引モータを支える上部固定基板の「前側支柱2点＋左右駆動マウント2点」。
これを**前側中央支柱1点＋左右駆動マウント2点**の3点へ変更した。
ファンモータマウント自体と上部固定基板を留める中央の2本のネジは維持する。

| 支持点 | X [mm] | Y [mm] |
|---|---:|---:|
| 前側中央支柱 | 0 | 8.5 |
| 左駆動マウント | −11.6 | 29.25 |
| 右駆動マウント | +11.6 | 29.25 |

前の2本の支柱と上下の固定ネジ4本を、中央支柱1本・上下ネジ2本へ置換する。
支柱は元ToraNekoの外径3・長さ8.5の形状を移動して使う。メイン基板の旧支柱穴2個を埋め、X=0、Y=8.5にΦ1.6の穴を1個設けた。
上板は厚さ0.6を維持し、外径12・モータ逃げΦ6.1の中心リングと幅3.6の3本の腕からなる形状に変更した。
各支持点の通し穴はΦ1.4、中心のファンマウント固定穴はX=±4.5、Y=21.75のΦ1.4を維持する。
元設計の4点支持板と異なる新規形状であり、ToraNekoの強度実績をそのまま引き継ぐものではない。

ファン軸Y=21.75、羽根Φ22、車軸Y=33、電池配置、センサの角度・位置を維持した。
センサはタイヤ寄りが前壁用±10°、機体前方が横壁用±60°（真正面0°）。
前側中央支柱は羽根の回転領域より前へ置く。ファン直下のΦ8吸入口とは別位置である。

## 確認と残る課題

[生成スクリプト](../mechanical/build_three_point_a11.py) / [3点化の形状生成](../mechanical/three_point_a11.py) / [検査JSON](../mechanical/sensor-a11-checks.json)

変更した上板・中央支柱・ネジ・メイン基板と全モデルの交差を確認する。
ネジと支柱下穴の重なりは意図したねじ掛かりとして別記する。
上板と中央支柱・左右駆動マウント・元ファンマウントの接触距離、羽根回転領域、センサ光軸中心線、外形、STEP読み戻しも確認する。
接触距離ゼロは支持面が接している確認であり、接触面積や強度を保証しない。

今回の出力は94部品・132ソリッド。センサ関連1670組、支持構造の変更関連455組、羽根回転領域25組を確認し、意図したねじ掛かり以外の食い込みを検出しなかった。8本の光軸中心線の遮蔽なし。各支持面の距離は許容1e-5 mm以内で接触し、STEP読み戻しも有効。

3点化で支柱1本・ネジ2本が減る一方、前側支持幅が狭くなる。厚さ0.6の板の曲げ・ねじれ、モータ振動、ねじの緩みを試作で確認する。
3点だから強度が上がる、あるいは必ず十分に固定できるとは扱わない。必要なら腕の幅、板厚、隅Rを見直す。
ねじ頭・長さは以前と同じ仮の占有形状。公差・はんだ・配線・接着剤・吸引ケース・スカートは未完成。
LTR-209も外形未確認の予約形状を継続する。重量・完成機重心は未更新。
